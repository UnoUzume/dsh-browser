# 实测记录：侧栏同页端到端（DSH NEXT 2.0.22-next，2026-11-20）

## 环境

| 组件 | 版本 / 形态 |
|---|---|
| DSH Desktop | `dsh-desktop-next` **2.0.22-next**（`Resources/app/` 解包布局，`app.asar.before-bridge` 保留原压缩包） |
| 插件 | `dsh-builtin-browser` **0.5.9**（装自 `github:UnoUzume/dsh-browser`，含本 fork 的全部侧栏修复） |
| 载体设置 | `browser.channel = "sidebar"` |
| bridge | 本 fork 的 `desktop-bridge/plugin-browser-bridge.js`，协议 3 |
| 平台 | macOS（Apple Silicon） |

## 安装过程（fork 安装器的三段 macOS 适配都用到过）

1. 进程检查：`pgrep -f "<bundle>/Contents/MacOS"` 判定外壳是否在跑（上游只有 PowerShell 实现）；
2. 压缩包校验：unpacked 条目只要求“存在且是普通文件”（打包后重新签名会改写 24 个二进制的 size，另有 9 个 0 字节 Python 包标记）；
3. 解包：unpacked 条目以文件本身为准，packed 条目仍按头部 size 严格校验；
4. 启动：`open -a <bundle>`（上游写死 `DeepSeek Harness.exe`）。

## 端到端结果

| 调用 | 结果 |
|---|---|
| `dsh_browser_open("https://example.com")` | 返回 `Example Domain`；**未产生独立窗口**（无自托管 Electron 进程） |
| `dsh_browser_snapshot()` | `[1] link: Learn more` |
| `dsh_browser_execute("document.title")` | `Example Domain` |
| `dsh_browser_click(target={by:"text",value:"Learn more"})` | `Clicked.` |
| `dsh_browser_wait(url="https://www.iana.org/help/example-domains")` | `Page ready.`（点击确实完成了跳转） |
| `dsh_browser_content({format:"json", selector:"h1"})` | `<h1 id="example-domains">Example Domains</h1>` |
| `bridge list`（全程） | `{"ok":true,"frame":"webview"}` |

## 附带结论

- `dsh-sidebar-browser/` 里的会话 ID 补丁与面板 owner 兜底**不再需要**：本 fork 已在源码层实现
  （`namesConversation()`、显示面板证据、`list` 的账本回退）。
- 同一个 `diagnose`（只读）在同一台机器上得到的 `viewports: 1 / webviews: 0` 只是**调用那一刻**的 DOM
  快照，不能据此判定面板形态；面板打开并放置页面后 `frame` 即为 `webview`。
